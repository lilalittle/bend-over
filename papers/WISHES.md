# Wishes for `papers/` — historical papers captured in the math DSL

Corpus wishes: the math of famous historical papers, expressed as
`math-dsl` terms. Parent: [root WISHES.md](../WISHES.md).
Changes need Tom's (@subtleGradient) recorded approval via PR.

### W-BO-PAPERS-1 · outcome · active
**Wish:** Each captured paper is a DSL source file plus provenance: full
citation, link to the original, and a note of which equations were captured
and which were skipped (with reason).
**Source:** W-BO-12.
**Check:** a newcomer can find the original paper from the capture alone.

### W-BO-PAPERS-2 · standing-duty · active
**Wish:** The canon grows in RCCM-first order. The seed is the lineage of
the rccm#3 electric-field dispute — Kelvin's "On Vortex Atoms" (1867) and
Maxwell's "A Dynamical Theory of the Electromagnetic Field" (1865). Tom
curates what comes next.
**Source:** Tom, chat 2026-10-03.
**Check:** each new capture names the theory thread it serves.

### W-BO-PAPERS-3 · invariant · active
**Wish:** Captures are data, not verdicts. A captured equation is never
presented as proved; promotion to a law happens in the BHAG pipeline
(bend-packages#65), never in the corpus.
**Source:** W-BO-13.
**Check:** corpus files carry no proof claims — only provenance and terms.
