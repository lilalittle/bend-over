    A SMALL BRIDGE, A REAL PROGRAM

    Follow the effect.

    Bend owns the sequence. A JavaScript handler carries out each request, then passes its result back.

    01 / DECLARE

    A typed boundary

    web.bend declares each effect with an IO return type and imports its JavaScript implementation.

    02 / PERFORM

    A browser action

    io_eff registers the handler. It can fetch JSON, update the DOM, wait for a timer, or save a value.

    03 / RESUME

    Back to Bend

    The browser runner awaits the result and resumes the program. The next effect starts when the last one finishes.
